Support

Mimir is a paid, offline arcade and learning app for iPhone and iPad. There is no account to create, and you do not need to be online to play.

Parent PIN

Purchases, settings, and parent tools are in the Parents area, behind a PIN. The default PIN is 1234. We recommend changing it after you install the app (Parents → Parent PIN). While the default PIN is still in use, buying a pack also asks a short grown-up multiplication question.

In-app purchases

Optional one-time packs (Game Pack 2, learning packs, and language packs) are sold only in Parents → Packs. Kids see a lock and a prompt to ask a grown-up — never a store. If you reinstall the app or get a new device, use Restore Purchases on the Packs screen with the same Apple ID.

Microphone (Hej Dansk)

Recording a parent’s voice is optional and happens only in the PIN-protected parent tools. If recording does not start, check Settings → Privacy & Security → Microphone → Mimir.

Get in touch

Email kevin@texasviking.com and include your device type and, if you can, the app version from the Parents area. We will help as quickly as we can.
